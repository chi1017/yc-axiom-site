Guide / 網站搬家指南

Weebly 搬家
完整指南.

網站搬家指南 Weebly / WordPress 閱讀時間約 8 分鐘 更新：2026/10/15

如果你的網站架在 Weebly，現在就是處理 Weebly 搬家的時候。Weebly 已公告停止包含台灣在內 67 個地區的服務，網站不搬，內容就會跟著下線。這篇整理 Weebly 台灣停止服務的時程、搬家前一定要備份的東西、Weebly 轉 WordPress 的步驟，以及轉址與 SEO 要注意的地方，最後附上常見問題。

我們是 YC AXIOM，實際幫按摩工作室完成過一次這樣的搬遷（見文末），所以除了公開資訊，也會分享實作時會遇到的細節。

Weebly 台灣停止服務：時程與原因

根據 Weebly 的公告與公開報導，這次是因為法規變動與簡化全球營運，Weebly 停止包含台灣在內 67 個地區的服務。重要日期如下（時程以 Weebly 官方公告為準）：

  • 2026/6/29：無法再發布新的頁面內容。
  • 2026/9/27：網站不再公開顯示，訪客看不到你的網站。
  • 2026/12/26：帳號無法再登入，下載資料與轉出網域的機會到這天為止。

也就是說，就算網站已經看不到，只要帳號還能登入，你仍然可以下載備份、轉出網域；過了 12/26 就來不及了。還沒處理的話，建議從今天開始。

Weebly 搬家前要備份什麼

先備份、再搬家。下面是我們搬遷前會逐項確認的清單：

  • 頁面文字與部落格文章：每一頁的標題、內文、服務說明與價目，連同現有網址清單。
  • 圖片與檔案：網站用到的原始圖片、PDF 與影片連結，盡量保留原圖，不要只存縮圖。
  • 網路商店資料：商品、訂單與顧客資料（如果有開 Weebly 商店）。
  • 表單與名單：聯絡表單的收件紀錄、電子報訂閱名單。
  • 網域與信箱設定：網域註冊商、DNS 設定，以及綁在網域上的信箱（含 Google Workspace）。
  • 流量與搜尋資料：Google Analytics、Search Console 的資料與驗證方式，之後要沿用。
  • SEO 設定：每頁的標題、描述與圖片 alt，搬家後要補回去。

依目前公開的操作說明，Weebly 的下載方式是登入後進入帳號的資料頁，選「下載個人資料」送出申請，等收到完成通知信，再用信中連結下載備份檔。資料量不大時，通常幾分鐘就會處理好。

要注意，下載到的是資料備份，不是一個能直接搬上新主機就運作的網站。版面、功能和頁面結構仍要在新平台上重新建置，這也是搬家需要花功夫的地方。

網域怎麼處理：Weebly 註冊的網域要轉出

如果你的網域是在 Weebly 註冊的，網域不屬於匯出的資料，需要另外轉到其他註冊商。依 Weebly 說明，網域註冊滿 60 天才能轉出；轉出前要在網域管理頁關閉註冊商鎖定，並取得 EPP 授權碼。

另外，轉出前如果變更了註冊人的聯絡資料，可能會觸發 60 天的鎖定，所以搬家期間不要隨意更動這些資料。解除鎖定也會關閉隱私保護，轉到新註冊商後記得重新開啟。網域轉移要預留時間，別拖到最後一週。

Weebly 轉 WordPress 的搬家步驟

不論自己動手或請人協助，Weebly 轉 WordPress 大致都是下面這八步：

  1. 01
    盤點頁面與網址

    列出所有頁面與現有網址，決定哪些保留、合併或刪除。

  2. 02
    備份資料與圖片

    照上面的清單先備份完，再開始動工。

  3. 03
    準備主機與 WordPress

    選擇主機、安裝 WordPress，並設定基本安全與自動備份。

  4. 04
    重建版面

    選擇或客製版型，重建原本的頁面結構。這一步通常花最多時間。

  5. 05
    搬入內容並補齊 SEO 設定

    貼入文字與圖片，補回每頁的標題、描述與圖片 alt。

  6. 06
    設定舊網址轉址

    把舊網址以 301 導向新網址，保留已累積的連結與搜尋紀錄。

  7. 07
    切換網域

    測試無誤後，再把網域指向新網站。

  8. 08
    上線後檢查

    手機與電腦逐頁檢查，提交 sitemap 到 Search Console，留意 404 與索引問題。

轉址與 SEO：搬家時最容易漏掉的事

  • 舊網址一一對應：Weebly 的頁面網址常見以 .html 結尾，WordPress 預設不是。沒有做轉址的話，舊連結會變成 404。
  • 使用 301 轉址：告訴搜尋引擎網址是永久搬家，而不是被刪掉。
  • 標題與描述不要遺失：搬完後每一頁都重新檢查一次。
  • 先搬家、再改版：搬家和大改版同時進行，出問題時很難判斷原因。時間緊迫時，建議先原樣搬，穩定後再優化。
  • 提交新的 sitemap、持續觀察：搬家後幾週，留意 Search Console 有沒有錯誤。

沒有人能保證搬家後排名完全不變，但把上面幾件事做好，可以把風險降到最低。

Weebly 搬家，一定要選 WordPress 嗎？

不一定。常見的選擇有三種：

  • WordPress：彈性高，網站檔案和主機都在自己手上，之後想加預約或電商功能也有空間；但需要有人定期更新與維護。
  • 其他拖拉式建站平台：上手快，但「平台說收就收」的風險依舊存在，這次的 Weebly 就是例子。
  • 客製程式碼網站：載入速度快、完全自有，適合重視品牌與長期使用；前期需要專業協助。

沒有標準答案，取決於預算、想自己維護多少，以及未來要不要加功能。

真實經驗：iMassage 的搬家重點

我們幫 iMassage 專業按摩搬過這一趟，最大的體會是：搬家最怕漏東西。所以先做完整清單、再動手，最後逐頁和舊站比對。他們選擇先原樣搬到 WordPress，其他優化等網站穩定後再做。實際做了哪些事、成果如何，整理在 iMassage 網站遷移案例。

Weebly 搬家常見問題

01. Weebly 真的會停止服務嗎？台灣也包含在內嗎？ +
是的。依 Weebly 公告，包含台灣在內共 67 個地區的服務將停止，原因是法規變動與簡化全球營運。2026/6/29 起無法發布新內容、9/27 網站停止公開、12/26 起帳號無法再登入。實際時程請以 Weebly 官方公告為準。
02. 現在還來得及備份嗎？ +
依公告時程，帳號在 2026/12/26 前仍可登入下載資料、轉出網域，所以還來得及。但建議越早處理越好，尤其網域轉出需要預留時間。
03. 我的網域是在 Weebly 買的，會跟著消失嗎？ +
不會自動消失，但要在帳號關閉前轉到其他註冊商，否則帳號關閉後你可能無法自行操作轉出。依 Weebly 說明，網域註冊滿 60 天才能轉出，並需要關閉註冊商鎖定、取得 EPP 授權碼，請提早處理。
04. Weebly 下載的備份可以直接匯入 WordPress 嗎？ +
依我們的經驗，通常不能直接使用。下載到的是資料備份，版面和功能需要在 WordPress 上重新建置，再把文字與圖片搬入。
05. Weebly 轉 WordPress 後，Google 排名會掉嗎？ +
沒有人能保證完全不變。網址有改變時，把舊網址用 301 轉址對應到新網址、保留每頁標題與描述、提交新的 sitemap，通常能降低影響。搬完後建議用 Search Console 持續觀察幾週。
06. Weebly 搬家要多久、費用多少？ +
依頁數、有沒有網路商店、要不要同時改版而定。小型店家的純搬遷通常比重新設計快很多，實際時程與報價要看現有網站。歡迎 LINE 傳現有網址給我們，免費評估後再報價。
