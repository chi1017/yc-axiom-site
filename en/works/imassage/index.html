Case Study / Real Project 01

Massage studio website.
The iMassage migration.

Client
iMassage (Taipei, an operating massage studio)
Project type
Website migration (move only, no redesign)
Platform
Weebly → WordPress
Scope
Content migration, domain transfer, basic SEO, pre-launch testing

Background

iMassage is an operating massage studio whose website had always been on Weebly. When the platform announced it was leaving Taiwan, the owner came to YC AXIOM with one request: move the site as-is to WordPress, which can be used long term, before the platform shut down, without ever losing the channel customers use to find them.

What We Covered

  • Every page, including service descriptions and prices.
  • All images used on the site.
  • Contact details: phone, address and opening hours, checked one by one.
  • Domain transfer and redirects from old URLs, plus basic meta information and a sitemap.
  • No redesign on purpose: the priority was getting all the content safely moved first.

How We Did It

  1. We made a migration checklist listing every page, image and service on Weebly.
  2. We set up WordPress and the layout, then moved each item on the list.
  3. We compared the new site with the old one page by page to make sure nothing was missing or wrong.
  4. We handled the domain transfer, checked everything on both phone and computer, and only then switched over.

Results

The site moved from Weebly to WordPress with all its content and service information intact, and customers never noticed the move. WordPress offers far more plugins and themes, so there is much more room to add online booking or change the layout later.

For what Weebly users should watch out for and back up before moving, see our general guide: The complete Weebly migration guide.
